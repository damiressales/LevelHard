# LevelHard

O **LevelHard** foi desenvolvido como meu primeiro projeto prático na faculdade. O objetivo foi estruturar uma aplicação web completa do zero, combinando navegação entre múltiplas páginas temáticas e uma experiência interativa através de um jogo autoral embutido diretamente no navegador.

## Funcionalidades

- **Página Inicial:** Apresentação geral do projeto e navegação entre as secções do site.
- **História:** Contextualização do enredo, universo e proposta narrativa do projeto.
- **Jogo Integrado:** Área interativa onde o jogo autoral é executado diretamente no navegador.
- **Comprar e Contacto:** Páginas dedicadas à vitrine de aquisição e ao envio de mensagens/contacto.

## Tecnologias Utilizadas

- **Estrutura:** HTML5
- **Estilização:** CSS3
